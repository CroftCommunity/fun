# 2048 — follow-ups

2048 ships as a Tier-1 game at `/2048/`: slide/merge with a verifiable
`pond-outcome` (score + best tile), tap-pad / swipe / keys input (core decides
legality), hints/settings, daily + free-play + `?r=` share, a How-to guide. Plan:
`plans/2026-07-31-2048.md`. Ideas for later, none blocking.

## Gameplay
- **Keep going after 2048.** v1 ends the round when the 2048 tile is made (a
  clean verifiable win). Add an opt-in "keep playing for a higher score" that
  continues past 2048 (the record would then carry the final score + a
  reached-2048 flag).
- **Undo.** A single-step undo (counts as assistance, like the other games), with
  the move popped from the record.
- **Best-score persistence.** Local-only best score + a per-day result, in
  `localStorage` (no server), matching the shelf's local-first stance.
- **Board sizes / targets.** The core parameterizes on width/height/`WIN_EXP`
  conceptually; expose 5×5 or a 1024 / 4096 target as variants with their own
  daily packs.

## Feel / polish
- **Tile animations.** Slide + merge + spawn transitions (respecting
  `prefers-reduced-motion`), matching the shelf's restrained motion. Currently the
  board re-renders instantly on each move.
- **Merge pop + score float.** A small "+N" on a merge, and a pop on the merged
  tile, for game feel.
- **Per-value colours.** v1 buckets tiles by magnitude (4 AA-clean buckets); a
  full 11-step ramp (one colour per value) is a nicety if it stays AA in both
  themes.

## Accessibility
- **Live-region move summaries.** Announce merges / new-tile placement for screen
  readers beyond the per-tile `aria-label`s.
